# bergwerk-media-2

베르크서울 상품 영상과 포스터를 jsDelivr CDN으로 제공하는 공개 미디어 저장소입니다.

## 업로드

업로드·변환·등록 방법은 이 문서에 적지 않습니다. 아래 지침을 따릅니다.

- [`jbk-stack`](https://github.com/seoraksanredcrayfish/jbk-stack)의 `product-detail-media` 스킬 문서
- 로컬 스킬 문서와 워크플로우

## 주의

- 파일명과 경로(CDN 링크)는 바꾸지 않습니다. 재업로드는 같은 이름으로 덮어씁니다.
- 홈페이지 소스, 비공개 자료, 인증정보는 올리지 않습니다.
